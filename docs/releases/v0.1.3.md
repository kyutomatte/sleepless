# Sleepless 0.1.3

Reliable AC auto-start update for the Sleepless macOS menu bar app.

## Assets

- `Sleepless_0.1.3_aarch64.dmg`
- SHA-256: `078b08e852aa3940a9d56330df5d7d95841cf8c4595455af8836d380859fbc05`

## Changes

- Persist `AC 연결 시 자동 시작` in the app configuration directory instead of the window-only browser storage.
- Move AC connection monitoring and automatic awake startup to the Rust menu-bar backend.
- Attempt automatic startup only once per AC connection so a cancelled administrator prompt is not repeated every five seconds.
- Migrate enabled preferences from earlier releases on first launch.

## Verification

- `pnpm build`
- `/Users/jongkyu/.cargo/bin/cargo test`

## Notes

Sleepless must be running in the menu bar to observe an AC connection. Enable `로그인 시 백그라운드 실행` to make it available after logging in.
